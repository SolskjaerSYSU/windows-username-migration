# Windows 中文用户名迁移实录

我的用户目录一直是 `C:\Users\中文名`。平时凑合能用，直到各种工具开始轮流出问题：包管理器隔三差五路径报错，某几个 CLI 在非 ASCII 路径下行为古怪，最后是 AI 编程工具的沙箱服务直接罢工。查了一圈，正解只有一个——把目录真正改成英文的。

网上主流教程是"新建账户、拷数据、重配环境"。我嫌那样脏：配置要重做，权限要重授，盘里还会多出一堆看不见的坑。所以选了另一条路：原位改名。前后失败五次，第六次成功，全程数据零丢失。这里放的是完整记录，外加一套改改就能用的脚本。

## 为什么敢说零丢失

因为整个方案不碰文件内容。同分区改目录名是纯元数据操作，一瞬间完成——不复制（就没有复制中断），不移动（就没有 ACL 丢失），失败了就当没发生过，回滚就是把名字改回去。

难的从来不是改名本身，是让 Windows 允许你改。

## 五次失败的原因

| # | 当时的现象 | 查出来的原因 |
|---|---|---|
| 1 | 备份时 NTUSER.DAT 报"正被另一进程使用" | "切换用户"进的恢复账户，旧会话还挂在后台。重启，必须是重启 |
| 2 | Rename-Item 报拒绝访问 | 13 个计划任务以旧账户身份运行，登录瞬间抢跑占住了目录 |
| 3 | 在登录界面干等三分钟，毫无动静 | "重启后自动登录"开着——系统根本没停在登录界面，早把我自动签进桌面了 |
| 4 | 按 SID 过滤计划任务，一个都没中 | 任务的 Principal 字段存的是账户名不是 SID，得两种一起匹配 |
| 5 | 上面全解决了，改名还是被拒 30 秒 | 一个自启动的沙箱服务握着目录根的句柄，开机就跑，赶在所有登录前面 |

第六次成功靠两件事：提前关掉自动登录；用 handle64 把占句柄的进程当场点名、停掉再改。

还有个插曲：迁移最后几秒正好撞上有人在登录界面输密码——账户名改到一半，密码怎么输都是错的。再重启一次就好了，但要是一开始就在脚本末段把账户临时禁用，就没这一出了。

各条坑的详细解法和代码在 [SKILL.md](SKILL.md)。

## 怎么用这套脚本

适用：本地账户，Win10/11。域环境没测过。

1. 先把 SKILL.md 读完，尤其是开头那几条原则
2. 改 `step2b_boot_rename.ps1` 头部的 `$newName` 和 SID 占位符
3. 备份：数据拷到另一块盘、注册表导出、建还原点、建个恢复管理员（`step1`）
4. 关自动登录（`step2d`），这步不做后面全白费
5. 跑 `step2b` 注册开机任务，然后重启
6. **停在登录界面等两分钟再输密码**，登录后跑 `step3` 验证
7. 正常用一周，确认没毛病，再删恢复账户和备份

| 脚本 | 用途 |
|---|---|
| `scan_config.ps1` | 扫出写死了旧路径的配置文件 |
| `step1_prepare_admin.ps1` | 恢复管理员 + 系统还原点 |
| `step2d_disable_arso.ps1` | 关"重启后自动登录" |
| `step2b_boot_rename.ps1` | 主脚本，开机时迁移；支持断点续跑，成功后自删 |
| `step2_rename_profile.ps1` | 交互式版本，备用 |
| `step3_verify.ps1` | 迁移后验证 |
| `clean_residual.ps1` | 清理漏网的旧路径 |

## 容易想当然的几个地方

- OneDrive 装了没登录 ≠ 没配置，注册表里的 UserFolder 一样要修。
- 旧路径的残留写法远不止一种：小写盘符 `c:\users\...`、正斜杠 `C:/Users/...`、TOML 的双反斜杠 `C:\\Users\\...`，再叠加 UTF-8 / UTF-16 / GBK 编码——最后是靠字节级替换、只匹配用户名本身才做到全覆盖。
- 计划任务的 Principal 有的存名字有的存 SID，迁移后恢复任务时两种都得筛。
- 带空格的服务名，`sc config "xxx" start= manual` 会翻车，用 `Set-Service`。
- 下载 Sysinternals 工具卡在证书校验时，`curl --ssl-no-revoke` 能救急。
- 迁移完一两天，VS Code 更新时弹出"安装程序不能创建目录 C:\Users\旧用户名"？
  是注册表卸载键（`Uninstall\..._is1` 的 InstallLocation）和文件关联
  （`Classes\Applications`）里的旧路径在作祟——软件自更新会按旧路径重装。
  这类键在 NTUSER.DAT 之外，常规迁移教程都会漏掉。

## 回滚

三处改回去：目录名、`HKLM\...\ProfileList\<SID>\ProfileImagePath`、账户名。具体命令在 SKILL.md 里。动手前留的备份（另一块盘上的数据副本、`.reg` 导出、NTUSER.DAT 副本、还原点）都是兜底。
